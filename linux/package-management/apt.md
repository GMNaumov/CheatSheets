# APT

```bash
sudo apt update
```

Под учётной записью суперпользователя обновляем **список** доступных пакетов и их версий (**не обновляя при этом сами пакеты**).

Скачанные данные сохраняются в `/var/lib/apt/lists/`.

---
```bash
sudo apt upgrade
```

Под учётной записью суперпользователя обновляем ранее установленные пакеты до последней актуальной версии.

При необходимости новые пакеты будут установлены как зависимости. Скачанные `.deb`-пакеты сохраняются в `/var/cache/apt/archives/`.

---
```bash
sudo apt update && sudo apt upgrade -y
```
Объединяем выполнение двух команд и автоматически отвечаем утвердительно на все вопросы (`-y`). В проде использование `-y` нежелательно (предпочтительно управляемое обновление).

`&&` — вторая команда будет выполнена только в том случае, если первая завершилась успешно.

Варианты:

`;` — вторая команда будет выполнена в любом случае, независимо от результата первой.

`||` — вторая команда будет выполнена только в том случае, если первая завершилась с ошибкой.

---
```bash
sudo apt autoremove
```
Удаляем ненужные зависимости после обновления.

---
```bash
sudo apt install -y ca-certificates curl
```

Устанавливаем от имени суперпользователя пакеты `ca-certificates` и `curl` — типичный шаг перед добавлением стороннего репозитория.

`ca-certificates` — пакет с корневыми сертификатами удостоверяющих центров.

`curl` — утилита терминала для передачи данных по сети, в том числе по HTTP и HTTPS.

---
```bash
sudo install -m 0755 -d /etc/apt/keyrings
```

Создаём каталог `keyrings` с правами 0755 от имени суперпользователя.

`0755` — режим доступа:

- владелец: чтение, запись, выполнение (`rwx`)
- группа: чтение и выполнение (`r-x`)
- остальные: чтение и выполнение (`r-x`)

`-d` — флаг, автоматически создающий родительские каталоги, если они ещё не существуют.
