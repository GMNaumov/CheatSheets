# APT

Справочник по обновлению списка пакетов, установке и очистке пакетов в системах с APT.

## Обновление

### Обновить список доступных пакетов

Обновляет сведения о доступных пакетах и их версиях, но не устанавливает новые версии. Списки сохраняются в `/var/lib/apt/lists/`.

```bash
sudo apt update
```

### Обновить установленные пакеты

Устанавливает доступные обновления. При необходимости APT добавит новые зависимости. Скачанные `.deb`-пакеты сохраняются в `/var/cache/apt/archives/`.

```bash
sudo apt upgrade
```

### Обновить список и пакеты одной строкой

Сначала обновляет список, затем пакеты. `&&` запускает вторую команду только при успешном завершении первой. Флаг `-y` автоматически подтверждает запросы APT; перед обновлением важных систем лучше просмотреть план изменений.

```bash
sudo apt update && sudo apt upgrade -y
```

**Другие операторы:** `;` запускает вторую команду независимо от результата первой, `||` — только если первая завершилась с ошибкой.

## Установка и очистка

### Найти пакет

Ищет пакет по названию или описанию. `apt show` выводит сведения о конкретном пакете.

```bash
apt search nginx
apt show nginx
```

### Установить пакет

Показывает план установки и запрашивает подтверждение.

```bash
sudo apt install nginx
```

### Удалить пакет

Удаляет пакет, но обычно сохраняет его системные настройки. Перед подтверждением проверьте список изменений.

```bash
sudo apt remove nginx
```

### Удалить ненужные зависимости

Удаляет автоматически установленные пакеты, которые больше не нужны. Перед подтверждением проверьте список удаления.

```bash
sudo apt autoremove
```

### Установить инструменты для HTTPS-репозитория

Устанавливает корневые сертификаты (`ca-certificates`) и сетевую утилиту `curl`. Флаг `-y` подтверждает установку без запроса.

```bash
sudo apt install -y ca-certificates curl
```

### Создать каталог для ключей репозиториев

Создаёт `/etc/apt/keyrings` с правами `0755`: владелец может читать, записывать и входить в каталог (`rwx`), остальные — читать и входить (`r-x`). Флаг `-d` у `install` создаёт каталог и недостающие родительские каталоги.

```bash
sudo install -m 0755 -d /etc/apt/keyrings
```
