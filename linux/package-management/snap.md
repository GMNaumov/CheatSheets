# Snap

Основные команды для поиска, установки, обновления и удаления приложений Snap.

## Найти приложение

```bash
snap find code
```

## Показать установленные приложения

```bash
snap list
```

## Установить Visual Studio Code

Флаг `--classic` предоставляет приложению расширенный доступ к системе.

```bash
sudo snap install --classic code
```

## Обновить приложение

Snap обновляет приложения автоматически; команда ниже запускает проверку и обновление вручную.

```bash
sudo snap refresh code
```

## Удалить приложение

Удаляет приложение `code`. Перед запуском убедитесь, что оно больше не нужно.

```bash
sudo snap remove code
```
