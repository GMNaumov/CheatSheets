# `mkdir`

`mkdir` (make directory) создаёт один или несколько каталогов.

Если каталог уже существует, команда без дополнительных флагов завершается с ошибкой.

## Создать каталог

```bash
mkdir reports
```

## Создать вложенные каталоги

Флаг `-p` создаёт недостающие родительские каталоги и не сообщает об ошибке, если каталог уже существует.

```bash
mkdir -p ~/a/b/c
```
