# `chmod`

`chmod` (change mode) изменяет права доступа к файлу или каталогу.

Команда не меняет и не перемещает содержимое файла. Изменять права может владелец файла или пользователь `root`.

## Группы пользователей

Права описываются тремя группами по три бита:

- `u` — **user**, владелец файла;
- `g` — **group**, группа файла;
- `o` — **others**, все остальные;
- `a` — **all**, все три группы сразу.

## Виды прав

Для каждой группы есть три основных права:

- `r` — **read**, чтение;
- `w` — **write**, изменение;
- `x` — **execute**, выполнение файла или вход в каталог.

**Пример:** запись `a+r` добавляет право на чтение для владельца, группы и всех остальных.

## Частые операции

### Сделать скрипт исполняемым для владельца

```bash
chmod u+x script.sh
```

### Задать права для обычного файла

`644` даёт владельцу чтение и запись, а остальным — только чтение.

```bash
chmod 644 config.txt
```

### Задать права для каталога или исполняемого файла

`755` даёт владельцу полный доступ, а остальным — чтение и выполнение. Для каталога право выполнения означает возможность входа в него.

```bash
chmod 755 script.sh
```
