# Основные команды Linux

Команды для навигации, просмотра и изменения файлов в терминале. Примеры выполняются в текущем каталоге; замените имена файлов и каталогов на свои.

## Навигация

### Показать текущий каталог

```bash
pwd
```

### Показать файлы, включая скрытые

```bash
ls -la
```

### Перейти в каталог

```bash
cd ~/Projects
```

`cd ..` возвращает в родительский каталог.

## Просмотр и поиск

### Прочитать файл

`less` открывает длинный файл постранично; для выхода нажмите `q`.

```bash
less README.md
```

### Найти текст в файлах

Показывает строки с совпадением и их номера. `-R` обходит вложенные каталоги.

```bash
grep -Rn "TODO" .
```

### Найти файл по имени

```bash
find . -type f -name 'README.md'
```

## Файлы

### Скопировать файл

Флаг `-i` запрашивает подтверждение перед перезаписью существующего файла.

```bash
cp -i config.example.yaml config.yaml
```

### Переместить или переименовать файл

```bash
mv -i old-name.txt new-name.txt
```

### Удалить файл

Удаление через `rm` не отправляет файл в корзину. Проверьте имя перед запуском; `-i` запросит подтверждение.

```bash
rm -i old-name.txt
```
