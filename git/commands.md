# Основные команды Git

Короткий набор команд для создания репозитория и ежедневной работы с изменениями, ветками и удалённым репозиторием.

## Начало работы

Для нового проекта настройте автора и создайте репозиторий. Если репозиторий уже существует на сервере, клонируйте его.

### Настроить автора коммитов

Git сохраняет имя и адрес электронной почты автора в новых коммитах. При настройке другого пользователя замените значения:

```bash
git config --global user.name "Georgii Naumov"
git config --global user.email "gmnaumov@yandex.ru"
```

### Создать репозиторий и первый коммит

Выполните команды в каталоге проекта:

```bash
cd my-project
git init
git add .
git commit -m "Initial commit"
```

### Клонировать существующий репозиторий

Создаёт локальную копию репозитория. Замените адрес и имя каталога на свои.

```bash
git clone https://github.com/username/my-project.git my-project
```

### Подключить удалённый репозиторий

Этот шаг нужен для репозитория, созданного через `git init`; после `git clone` удалённый репозиторий `origin` уже настроен. Замените URL на свой. `git remote -v` проверяет сохранённый адрес, а `git branch -M main` задаёт имя текущей ветки перед первой отправкой:

```bash
git remote add origin https://github.com/username/my-project.git
git remote -v
git branch -M main
git push -u origin main
```

## Изменения и коммиты

### Проверить состояние

Показывает изменённые, подготовленные и новые файлы.

```bash
git status
```

### Посмотреть изменения

Первая команда показывает изменения в рабочем каталоге, вторая — уже добавленные в индекс.

```bash
git diff
git diff --staged
```

### Добавить файлы и создать коммит

Укажите нужные файлы вместо `README.md`, проверьте состав коммита и запишите изменение.

```bash
git add README.md
git diff --staged
git commit -m "Обновить документацию"
```

### Посмотреть историю

```bash
git log --oneline -10
```

## Ветки и обмен изменениями

### Создать ветку и переключиться на неё

```bash
git switch -c feature/docs
```

Для перехода в существующую ветку используйте `git switch main`, заменив `main` на её имя.

### Получить изменения и отправить коммиты

`git pull --ff-only` обновляет текущую ветку, только если возможна перемотка без слияния. `git push` отправляет локальные коммиты в настроенную удалённую ветку.

```bash
git pull --ff-only
git push
```

## Отмена локальных действий

### Убрать файл из индекса

Сохраняет изменения в рабочем каталоге, но исключает файл из следующего коммита.

```bash
git restore --staged README.md
```

### Отменить изменения в файле

Команда удалит изменения в рабочем каталоге, ещё не добавленные в индекс. Подготовленные изменения сохранятся. Перед запуском проверьте `git diff README.md`.

```bash
git restore README.md
```
