# Команды Docker

Краткий справочник по контейнерам, сервисам Docker Compose и томам. Команды Compose выполняются в каталоге с compose-файлом.

## Сервисы Docker Compose

### Запустить сервисы в фоне

Запускает все сервисы, описанные в `compose.yaml`, `compose.yml`, `docker-compose.yaml` или `docker-compose.yml`.

```bash
docker compose up -d
```

Флаг `-d` (`detach`) запускает контейнеры в фоне.

### Пересоздать один сервис

Принудительно пересоздаёт контейнер сервиса `dsh` без пересборки образа.

```bash
docker compose up -d --force-recreate dsh
```

## Контейнеры

### Показать все контейнеры

Выводит запущенные и остановленные контейнеры.

```bash
docker ps -a
```

**Альтернативная запись:** `docker container ls -a`.

### Показать остановленные контейнеры

Отбирает контейнеры со статусом `exited`.

```bash
docker ps -a -f "status=exited"
```

### Удалить контейнер

Удаляет остановленный контейнер по имени или ID. Запущенный контейнер сначала остановите командой `docker stop <имя_или_id_контейнера>`.

```bash
docker rm <имя_или_id_контейнера>
```

Флаг `-f` позволяет принудительно удалить запущенный контейнер; используйте его только если остановка и удаление действительно нужны.

## Тома

### Показать тома

```bash
docker volume ls
```

### Удалить том

Удаляет указанный том. Docker не позволит удалить том, подключённый к контейнеру. При удалении тома данные в нём теряются.

```bash
docker volume rm <имя_тома>
```

Можно указать несколько имён томов через пробел.
