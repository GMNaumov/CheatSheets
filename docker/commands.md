# Команды Docker

Краткий справочник по контейнерам, сервисам Docker Compose и томам. Команды Compose выполняются в каталоге с compose-файлом.

## Сервисы Docker Compose

### Запустить сервисы в фоне

Запускает все сервисы, описанные в `compose.yaml`, `compose.yml`, `docker-compose.yaml` или `docker-compose.yml`.

```bash
docker compose up -d
```

Флаг `-d` (`detach`) запускает контейнеры в фоне.

### Пересоздать один сервис

Принудительно пересоздаёт контейнер сервиса `dsh` без пересборки образа.

```bash
docker compose up -d --force-recreate dsh
```

### Посмотреть состояние сервисов

Показывает контейнеры проекта, их состояние и опубликованные порты.

```bash
docker compose ps
```

### Посмотреть логи сервисов

Показывает последние строки и продолжает выводить новые сообщения. Остановить просмотр можно сочетанием `Ctrl+C`; контейнеры продолжат работать.

```bash
docker compose logs --tail=100 -f
```

Для одного сервиса добавьте его имя в конце команды.

### Остановить проект

Останавливает и удаляет контейнеры и сеть Compose. Именованные тома остаются на месте.

```bash
docker compose down
```

### Выполнить команду внутри сервиса

Выполняет команду в работающем сервисе. В примере сервис `ollama` выводит список локальных моделей; замените имя сервиса и команду для своего проекта.

```bash
docker compose exec ollama ollama list
```

## Контейнеры

### Запустить временный контейнер

Запускает оболочку в образе Alpine. Если образа нет локально, Docker скачает его; после выхода из оболочки контейнер удалится.

```bash
docker run --rm -it alpine sh
```

### Показать запущенные контейнеры

```bash
docker ps
```

### Показать все контейнеры

Выводит запущенные и остановленные контейнеры.

```bash
docker ps -a
```

**Альтернативная запись:** `docker container ls -a`.

### Показать остановленные контейнеры

Отбирает контейнеры со статусом `exited`.

```bash
docker ps -a -f "status=exited"
```

### Удалить контейнер

Удаляет остановленный контейнер по имени или ID. Запущенный контейнер сначала остановите командой `docker stop <имя_или_id_контейнера>`.

```bash
docker rm <имя_или_id_контейнера>
```

Флаг `-f` позволяет принудительно удалить запущенный контейнер; используйте его только если остановка и удаление действительно нужны.

### Остановить и снова запустить контейнер

Замените имя на имя своего контейнера. При остановке выполняющиеся в нём процессы завершатся.

```bash
docker stop my-container
docker start my-container
```

### Посмотреть логи контейнера

```bash
docker logs --tail=100 -f my-container
```

Остановить просмотр логов можно сочетанием `Ctrl+C`.

## Образы

### Показать локальные образы

```bash
docker image ls
```

### Загрузить образ

Загружает образ в локальное хранилище без запуска контейнера.

```bash
docker pull nginx:stable
```

## Тома

### Показать тома

```bash
docker volume ls
```

### Удалить том

Удаляет указанный том. Docker не позволит удалить том, подключённый к контейнеру. При удалении тома данные в нём теряются.

```bash
docker volume rm <имя_тома>
```

Можно указать несколько имён томов через пробел.
