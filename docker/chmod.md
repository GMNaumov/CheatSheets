`chmode` - change mode

Утилита используется для изменения прав доступа к файлу или каталогу. Не меняет и не перемещает содержимое файла.

Изменение прав доступно владельцу файла (или каталога) и пользователю `root`.

Описание прав хранится в трёх группах по три бита:

- `u` - **user**, владелец файла;
- `g` - **group**, группа файла;
- `o` - **others**, все остальные;
- `a` - **all**, все три группы сразу;

Для каждой группы есть три основных права:

- `r` - **read**, чтение;
- `w` - **write**, изменение;
- `x` - **execute**, выполнение для файла, вход для каталога;

Запись `a+r` означает: *добавить право на чтение для владельца, группы и всех остальных*.
