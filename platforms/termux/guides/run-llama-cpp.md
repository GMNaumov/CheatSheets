#### ...почти каждому 40-летнему мужику иногда приходит в голову мысль: "А что, если телефон на Android превратить в Linux-сервер и запустить внутри него локальную LLM?"

Инструкции ниже предполагают, что на телефоне установлен `Termux` - приложение, которое максимально точно имитирует терминал Linux.

---
```bash
termux-setup-storage
```

Даём termux доступ к файловой системе телефона (Android попросит разрешение, которое нужно предоставить)

---
```bash
pkg update -y && pkg upgrade -y
```

Обновляем пакеты. Всё просто и понятно

---
```bash
pkg install -y proot-distro git curl wget termux-exec
```

Почти всё понятно, за исключением `proot-distro`. Этот пакет создаёт изолированное окружение (например, какая-нибудь Ubuntu), которое будет выступать в качестве заменителя Docker, который в чистом виде внутрь Android установить не получится

---
```bash
proot-distro install Ubuntu
```

Устанавливаем Ubuntu, внутри которого будет выполнять все действия

---
```bash
proot-distro login ubuntu --isolated
```

Входим внутрь установленного окружения. `--isolated` обязательно, чтобы избежать конфликтов окружения с Termux.

---
Действия далее выполняются внутри созданного окружения - по сути, это обычные команды терминала Ubuntu

---
```bash
apt update -y && apt upgrade -y
apt install -y build-essential git cmake
```

Обновляем пакеты, устанавливаем Git и инструменты сборки (да, собирать будем из исходников, только хардкор)

---
```bash
git clone https://github.com/ggerganov/llama.cpp.git
cd llama.cpp
cmake -B build -DGGML_NATIVE=ON
cmake --build build --config Release -j$(nproc)
```

Клонируем репозиторий и собираем его. Технически, можно подключить оптимизации, но сработает и так.

Сборка будет выполнена в каталог `build/bin/llama-server`
