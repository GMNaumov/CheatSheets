# Основные команды Spring Boot

Команды для проекта Spring Boot с Maven Wrapper (`mvnw`). Выполняйте их из корня проекта, где находится `pom.xml`.

## Запустить приложение

Запускает приложение в режиме разработки; остановить его можно сочетанием `Ctrl+C`.

```bash
./mvnw spring-boot:run
```

## Запустить тесты

```bash
./mvnw test
```

## Собрать приложение

Запускает тесты и создаёт исполняемый JAR в каталоге `target/`.

```bash
./mvnw clean package
```

Если в проекте нет Maven Wrapper, замените `./mvnw` на установленный `mvn`.
